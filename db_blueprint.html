Landed Cost Calculation

Calculates the actual cost of acquiring metal including all import and shipping fees. This determines the Average Unit Cost for a Lot.

LandedCost = TotalCost + FreightCost + InsuranceCost + CustomsDutyCost + OtherFees

General Ledger Double-Entry

Every physical movement must be balanced by a financial posting to ensure accounting integrity.

Step 1: Create gl_journal_entries record
Step 2: Create gl_journal_lines (Debit: Asset Account)
Step 3: Create gl_journal_lines (Credit: Liability/Cash Account)

Chain of Custody Tracking

Records every time a physical bar is moved from one location to another for auditing purposes.

Trigger: UPDATE InventoryItem SET LocationId = @NewLoc
Action: INSERT INTO CustodyLog (ItemId, OldLoc, NewLoc, User, Time)

Finance Total Inventory Valuation

Calculates the current book value of all on-hand precious metals.

SELECT SUM(I.Weight * L.AverageUnitCost) as TotalValue
FROM InventoryItem I
JOIN InventoryLot L ON I.LotId = L.LotId
WHERE I.StatusCode = 'READY'

Audit LBMA Compliance Gap

Identifies bars that are missing mandatory LBMA certification data.

SELECT SerialNumber, ProductCode
FROM InventoryItem
WHERE RefinerName IS NULL OR FinenessPpt IS NULL
